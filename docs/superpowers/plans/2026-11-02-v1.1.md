# Meander v1.1: "do it all" (Steven, 2026-11-02)

Built interactively in one session. Ledger at the bottom; tick as each lands.

Rulings made up front (Steven said "do it all" to the open questions):
- Saving: both. Autosave to IndexedDB (one slot, every 20 s while running and
  when the tab is hidden) and Save/Open a `.meander` file (gzip). A share link
  in the URL wins over the autosave.
- Braided rivers: build them. New `pattern` setting: meandering (default, so
  existing links are unchanged), braided, auto (picks from slope x sqrt(Q) x
  sediment supply). Valley slope range widened to 0.01.
- Close-up pass: done in this session, not as an autonomous run.
- Time-lapse: WebM via MediaRecorder with the year burnt in; no GIF.
- Phones: drop the 1024 px gate, Low quality by default on coarse pointers,
  touch toolbar, responsive panels. No new quality tier.
- Firefox determinism: only if a Firefox build is already on this machine.
- Analytics token and real-display fps stay with Steven.

Guard: a golden test pins the default river (seeds 1-3) so nothing here
changes existing share links.
